# HN: agents and memory, 2026-11-13

- [Brave Search API now accepts agentic payments via the x402 protocol](https://brave.com/blog/search-api-agentic-payments/), 165 points, 92 comments ([HN](https://news.ycombinator.com/item?id=50477649)). Most worth reading: agents can pay for search calls on their own, and the thread should show how people expect agent payments to work in practice.
- [Show HN: AgentRun – open-source, Self-improving Managed Agents](https://github.com/Parcha-ai/agentrun/blob/main/README.md), 120 points, 29 comments ([HN](https://news.ycombinator.com/item?id=50471650)). An open-source agent platform that claims agents improve themselves over time, so check the thread for how well that holds up.
- [Show HN: Kapso – Iterative learning from enterprise data](https://news.ycombinator.com/item?id=50471281), 51 points, 11 comments ([HN](https://news.ycombinator.com/item?id=50471281)). Open-source system for learning from enterprise data over repeated runs, which is the nearest thing here to agent memory.
- [Relate – the agent-native graph database](https://relatedb.ai/), 22 points, 9 comments ([HN](https://news.ycombinator.com/item?id=50472738)). A database pitched for agents' state and retrieval needs, so skim it for how it frames agent storage.

Skipped: Expo Simulators (a tooling launch for agents, nothing on memory or state) and Cerulion (robotics runtime, off topic).
